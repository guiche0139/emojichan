# Emojichan

一款专注于表情包管理和快捷发送的 Android 应用。

## 功能特性

- **表情包网格展示** - 3列网格布局，清晰浏览所有表情包
- **多格式导入** - 相册导入图片/GIF/PNG/WebP/BMP，自动保留原始格式（**v0.1.408 起 WebP 走通导入 / 分享 / 剪贴板 / 相册发布 / 归档 / 导出全链路**，动画 WebP 也认得出）；**一次可以勾选多张**，按选择顺序依次导入，期间显示进度、结束报数量
- **实时搜索** - 按名字或标签名搜索，可与标签、收藏组合使用；支持多条件语法：`$标签名$` 或 `$TAG=标签名$` 按标签搜、`@关键词@` 只看名字、不带符号的词两边都算，`&` 同时满足、`/` 任一满足（先算 `&` 再算 `/`）；输入 `$` 时搜索框下面会弹出标签候选列表（不挤走下面的表情），搜索框上面还有标签 / 关键词 / 和 / 或四个快捷按键
- **标签是唯一的组织方式** - 一个表情可同时挂多个标签（多对多），没有「包」这一层；筛选支持「同时满足 / 任一满足」，详情页与多选「整理」都能增删标签
- **标签面板** - 筛选条最左侧的展开按钮拉开面板：所有标签**网格排列**，单击即筛选，长按可重命名 / 删除；面板里还有「同时满足 / 任一满足」、新建标签与管理标签；顶部筛选条本身就是「当前分类」的位置，「全部」与「收藏」是固定在最前面的两颗 chip
- **批量整理** - 多选后可一次性添加标签 / 移除标签
- **导入不重名** - 名字自动取原文件名（去掉扩展名），重名自动加序号（猫猫 → 猫猫(1)），不会覆盖已有表情；按格式自动挂「图片」或「动图」标签（想改名在详情页改）。**拿不到原名时**（云相册图片在系统选择器里只有一串数字 id，任何应用都读不到真名）会用导入时间命名成「图片 09-28 14:05」，而不是一串看不懂的数字。**数字真名不会被当成 id 丢掉**：微信/QQ 保存的图片原名本身就是 17 位数字（如 `1727512345678.jpg`），只有与 Uri 末段一字不差的纯数字才被当作选择器漏出的 id，真名一律原样保留。**（v0.1.311）**判据再收紧并贯穿整条命名链：显示名是 id **带扩展名**（`1000000033.jpg`）也照样拦下；每一次落库都会把原名与各来源的证据写进发送日志（tag `导入`），拿不到原名时导入结果也会明说有几张用了时间名；导入按钮现在**先问从哪里导**——「从相册导入」（可多选；Android 13+ 走系统相册选择器的正式接口，拿到的是真实媒体条目）或「从文件导入」（系统文件选择器，显示名就是磁盘上的真文件名，名字总不对时走这条；打开即落在「图片」根）；**（v0.1.315）**新增「从文件夹导入」：选一个文件夹，里面的图片按**文件夹名自动打标签**（子文件夹各成一标签、上层标签也保留，重名规则与单表情一致）；**（v0.1.314）**又从系统里多挖出一条路——同一个 id 拿去问文档 provider 往往能给回真名（实测相册那条路只肯给 `1000531098.jpg`，文件那条路给的是 `1790668073824.jpeg`），且反查改成逐卷查；若这些路都因为**没有相册读权限**而被系统挡住，导入来源与结果提示里会出现「允许读取相册（导入时用原文件名）」——**不授权照样能导入**，授权只是让名字有处可问
- **分享导入** - 在别的应用里把图片「分享」到 Emojichan 即可导入，支持一次多张
- **收藏功能** - 常用表情一键收藏
- **多选删除** - 批量删除多个表情包（自动清理本地文件）
- **详情预览** - 大图预览（**v0.1.409 起整张完整显示**，长图 / 宽图不再被裁掉两头），查看格式/大小/尺寸等详细信息与所属标签，支持重命名
- **悬浮球快捷发送** - 屏幕上常驻一个悬浮球，点开选中表情即可发到微信 / QQ：静态图走剪贴板自动粘贴并发送，动图走系统分享（也可切到「＋ → 相册」以保留动画）
- **自动选中聊天对象** - 发送前读一次当前聊天窗口的名字，在微信的「选择聊天」列表里自动选中同名的那一项；认不出来时只需自己点一下
- **最后一步可以自己点** - 设置页的「最后一步自动确认」开关：开着（默认）程序替你点微信的「发送」/ QQ 的「确定」；关掉则流程停在按钮前，由你自己点最后一下
- **面板里按标签挑** - 悬浮球面板顶部是最近 / 全部 / 收藏三颗 chip，下面一行是标签，选完标签立刻筛出对应表情
- **悬浮球只在勾选的应用里出现** - 设置页「悬浮球出现在哪些应用」自己挑（默认微信 + QQ，也可以清空 = 所有应用）；这个范围与「无障碍自动发送」是两件事：自动选中聊天对象仍然只在微信 / QQ 里做
- **状态栏一键开关** - 下拉状态栏的快捷磁贴「表情悬浮球」点一下就能开 / 收悬浮球（磁贴要自己拖进面板一次，系统没有提供应用代劳的接口）
- **复制到剪贴板** - 表情详情页有「复制到剪贴板」按钮，可把图片（含 GIF）放进系统剪贴板，供任意应用粘贴
- **发送日志** - 记录每次发送走了哪条路线、结果如何，**v0.1.413 起按普通 / 警告 / 错误三级显示**（错误标红、警告标黄），出问题时可以直接复制出来，也能导出成 TXT；**一出现错误就自动存一份错误日志**（最多留最近 20 份，日志页能查看并导出）
- **主题色** - 两套配色取自应用图标本身的两个颜色：天空蓝（默认）与樱花粉；浅色与深色各配一套，跟随系统深色模式
- **悬浮球外观可选** - 默认（扁平猫脸，就是应用图标那张）/ 游戏开发部（像素猫）/ 纯色表情球 / 从相册挑一张
- **高级设置页** - 表情原文件处理、大表情压缩（**v0.1.408 新增**：压缩用有损还是无损、压缩页要不要列出动图；**v0.1.409 起压缩默认无损**）、**重复与相似检索**（**v0.1.412 新增**：画面相近判定的底线；**v0.1.413 起按相似度百分比显示**）、发送方式、诊断（发送日志 + **v0.1.414 起多一行「使用引导」**）集中在「设置 → 高级设置」
- **表情库迁移** - 就在设置页里（「高级设置」上面那一段）：导出成一个带清单的 `.emcpack` 包（表情连同标签、收藏、尺寸、导入时间），换手机时导回；「添加」会自动跳过库里已经有的，「覆盖」先弹确认再清空重来；旧版导出的 `.zip` 包照样能导入
- **存储管理** - 设置页最上面那一段：先看清表情库占了多少（环形图 + 各格式的张数 / 体积 / 占比，另列数据库、缓存与总占用，都按磁盘实际占用算）；里面两个入口 —— **大表情压缩**（三列网格，按 10MB 以上 / 1–10MB / 1MB 以下分段，勾几张静图压缩：**不动分辨率**，只把原图重新编码成 WebP，有损是质量 80、无损逐像素一致（API < 30 上无损落 PNG），**只有确实变小才替换**，压不小或图太大解不动的会照实报出来；动图默认不列出来，想看到高级设置里打开；压完先进预览页对比，按住能看原图，点「替换」才真的换掉，也可以先把这批原图导出成一个 zip））、**重复与相似检索**（点开直接比对，**两类结果同页**：上面「内容完全相同」按文件内容比对 —— 先按体积分桶，只有体积一样的才去算 SHA-256，摘要相同的分成一组、一组一行，点缩略图就能改保留哪张，删之前先问；指纹存在库里当缓存，第二次进页面基本不读盘。下面「画面相近」按感知哈希 dHash 比对，结果按相似度由高到低排（相似度 88% 及以上的归为一组，底线可在「设置 → 高级设置 → 重复与相似检索」里改成 94% 或 81%），缩过、压过、改过亮度、加过留白的同一张图会列在一起，改了底线回页面不用重新读盘；结果只当候选 —— 点缩略图是选中要删的那张、长按进去看大图，删哪张由你定）
- **导出表情** - 主页长按进多选（或点「全选」），底栏「导出 N」能把选中的几张存到一个文件夹或打包成一个 zip；详情页的「导出图片」把当前这张按原名另存一份。两种都只写副本，不会动表情库里的原图
- **导入后源文件怎么处理** - 「保留（默认）/ 压缩成 zip（先写成功包、再删源文件）/ 删除」三选一，只针对这一次导入选中的那些文件，不碰你其他任何东西
- **危险操作都先问一句** - 删表情、删标签、覆盖导入、打开「删除源文件」策略、打开「最后一步自动确认」，都要二次确认
- **首次打开的使用引导** - **v0.1.414 新增**：第一次进应用会走四步说明（这个应用做什么 / 悬浮球权限 / 自动发送服务 / 相册读权限，三步权限都能在页面里直接跳去系统设置、回来就看状态）；不想看可以「跳过」，**跳过前会再确认一次**；之后想重看：设置 → 高级设置 → 诊断 → 使用引导
- **版本页** - 设置页「关于」里点「版本」进入：上面是应用图标、名字与版本号，下面是 GitHub 入口，一键跳到发布页（联网交给浏览器，应用自己始终不联网），也能只复制下载链接

## 技术栈

- **开发语言**：Kotlin
- **最低版本**：Android 8.0 (API 26)
- **架构模式**：MVVM
- **数据库**：Room 2.6.0（DB v5：标签多对多结构 + 图片指纹缓存表，含 v1→v2、v2→v3、v3→v4、v4→v5 迁移）
- **图片加载**：Glide 4.16.0
- **UI组件**：Material Design 1.11.0
- **异步处理**：Coroutines 1.7.3
- **依赖管理**：Gradle Version Catalog
- **测试**：JUnit 4 + Robolectric 4.11.1 + Room in-memory

## 使用说明

> 第一次打开应用会走一遍**使用引导**（四步：这个应用做什么 / 悬浮球 / 自动发送服务 / 相册读权限），每一步都能直接跳到对应的系统设置页、回来就能看到状态；不想看可以「跳过」，**跳过前会再确认一次**。之后想重看：「设置 → 高级设置 → 诊断 → 使用引导」。

1. **导入表情包** - 点击底部"导入"按钮，从相册选择图片（**可长按多选，一次导入多张**，会按顺序一张张处理并显示进度）；名字自动取原文件名（重名自动加序号），想改名去详情页；万一拿不到原名（云相册图在系统选择器里只有一串它自己的数字 id），会用导入时间命名成「图片 09-28 14:05」（**真名本身就是数字的图不算在内**，微信/QQ 存的 `1727512345678.jpg` 会原样保留）。导入完成的提示条上有「再导入一批」，可以接着挑下一批；点「导入」会先问**从哪里导**：相册那条能多选、界面好看；文件那条（系统文件选择器）名字与原文件一致；文件夹那条会把整个文件夹（含子文件夹）导进来，并按**文件夹名自动打标签** —— 如果这次有图没读到原名，提示条上的按钮会直接变成「从文件导入」
2. **搜索** - 在顶部搜索框输入关键词，可与标签、收藏组合使用。想按标签搜就写 `$标签名$`（或 `$TAG=标签名$`），想只在名字里找写 `@关键词@`，不带符号的词两边都算；`&` 表示同时满足、`/` 表示任一满足，例如 `$TAG=猫$ & @生气@ / $TAG=狗$` 就是「猫且名字含生气」或者「狗」。输入 `$` 时搜索框下面会弹出标签候选（关键词不参与联想），点一条就补进搜索框；搜索框上面那四个按钮能直接插入这些符号，右端「用法」里有一段说明
3. **标签** - 点筛选条最左侧的「标签」按钮拉开标签面板：网格里点标签即筛选（可多选，再用「同时满足 / 任一满足」切换匹配方式），长按标签可重命名 / 删除，面板底部还有「新建标签」与「管理标签」；选中的标签会直接显示在筛选条上，「全部」用来清除筛选、旁边的「收藏」只看收藏
4. **整理** - 长按进入多选模式后，点"整理"可批量添加标签 / 移除标签
5. **存储管理** - 「设置 → 存储」：上面是概览（环形图 + 各格式张数 / 体积 / 占比，下面还有数据库、缓存与总占用），下面两个入口。进「大表情压缩」能看到三列网格，按 10MB 以上 / 1–10MB / 1MB 以下分段，**动图默认不列出来**（想连动图一起看，去「设置 → 高级设置 → 大表情压缩」把「压缩页里的动图」切成「显示」）；勾几张静图点「压缩」，压完先进预览页，**按住任意一张的「按住看原图」能对比压缩前后**，觉得可以再点「替换这 N 张」；不想换就返回，原图一点没动。**压之前建议先导一个备份包**（「设置 → 表情库迁移 → 导出表情库」）。压缩**不改分辨率**，只是重新编码：**v0.1.409 起默认无损**（逐像素一致，但常常压不小 —— 那种图会按「没变小」跳过），想去高级设置**切成有损**就换成 WebP 质量 80；动图不能压；横拍的照片会先按拍摄方向转正，不会躺倒。想把这批原图留一份，压缩页底部可以直接「导出原图…」打包成 zip。概览卡片下面还有一行「清除缓存」：点它先问一句，确认后把 Glide 的图片缓存与 `cacheDir` 一起清掉，表情、标签和设置都不动。另一个入口是**重复与相似检索**，点开直接比对，**两类结果同页**：上面「内容完全相同」按文件内容比对（一模一样的才成组，被压过、缩过的图不算，会落到下面「画面相近」那一段），下面「画面相近」按感知哈希比对（结果按相似度由高到低排，相似度 88% 及以上的归为一组，底线在「设置 → 高级设置 → 重复与相似检索」里可选 94% / 88% / 81%；缩过、压过、改过亮度的同一张图会列在一起；点缩略图是选中要删的、长按看大图，删哪张由你定 —— 相近不等于相同，程序只把候选摆出来）
6. **导出表情** - 主页长按任意一张进入多选，勾好之后底栏会出现「导出 N」：可以「保存到一个文件夹」（逐张写进去）或「打包成一个 zip」；详情页底部也有「导出图片」，把这单独一张按「名字.扩展名」存到你想存的位置。两种导出都只是复制，**不会删除或改动库里的表情**
7. **收藏** - 点击星标图标收藏/取消收藏
8. **删除** - 长按进入多选模式，选择后点击删除（本地文件一并清理）
9. **查看与复制** - 单击表情包查看大图和详细信息；详情页的"复制到剪贴板"按钮可把图片放进系统剪贴板，供任意应用粘贴
10. **悬浮球与状态栏开关** - 在设置页「悬浮球出现在哪些应用」里勾选它该出现的应用；把状态栏快捷面板里的「表情悬浮球」磁贴拖出来，之后点磁贴即可随手开 / 收悬浮球（磁贴添加需手动一次：下拉状态栏 → 编辑 → 把「表情悬浮球」拖上去）
11. **导入名字不对时** - 「设置 → 高级设置 → 发送日志」，找 tag 为 `导入` 的行：`采用名=…` 后面会跟上这一张图在各来源（显示名 / DATA 列 / Uri 末段 / 选择器换算结果）里的原始值，据此能看出是系统选择器没给真名，还是解析出了问题
12. **换手机 / 备份** - 「设置 → 表情库迁移 → 导出表情库」存成一个 `.emcpack` 包（标签与收藏都在包里）；在新手机装好后用「导入表情库」把包导回来：选「添加」只补缺的（同一张图按名字 + 体积自动跳过），选「覆盖」会清空现有库再导入（会先弹一次确认）。原来是相册里的图，导出后也存在包里，不再依赖原手机。

## 隐私说明

- 本应用**没有申请联网权限**，清单里只申请了「显示在其他应用上层」（悬浮球）一条权限；导入图片走系统自带的图片选择器，不需要读相册权限（有一项**可选**的相册读权限，只为把导入文件的原始文件名读出来，不授权也能正常导入）。所有表情、标签、日志都只存在本机。
- 「表情自动发送」无障碍服务只在两个时机读取屏幕内容：① 判断前台应用是不是微信 / QQ；② 你点选表情后读一次聊天窗口标题。它不采集、不保存、不上传聊天内容。
- 悬浮球需要「显示在其他应用上层」权限；Android 13 及以上如果开关是灰的，需要在系统设置的「受限设置」里允许本应用。
